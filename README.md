# Alatyr — ретранслятор AmneziaWG с раздельной маршрутизацией

Один исполняемый файл. Подключается к вашему AmneziaWG-серверу, сам принимает
пользователей (AmneziaWG 1.0, 2.0, 3.1 и обычный WireGuard) и для каждого
соединения решает: пустить его через VPN или напрямую — по спискам доменов и
подсетей.

```
                                            ┌─► AWG (vpn.conf) ──► ваш VPN-сервер ──► интернет   (сайты из списков)
телефон/ноутбук ─AWG 1.0/2.0/3.1/WG─► Alatyr┤
                                            └─► напрямую с IP этой машины ──► интернет           (всё остальное)
```

- Ничего не меняет в системе (без TUN, маршрутов, DNS), права администратора не нужны.
- Всё настраивается в веб-морде: пользователи, `.conf`, ссылка `vpn://`, QR-коды, маршрутизация.
- Данные — один файл `alatyr-data.json`.

## Быстрый старт

1. Положите рядом с бинарником конфиг вашего VPN-сервера `vpn.conf` и `config.yaml`.
2. Запустите:
   ```sh
   ./alatyr --config config.yaml          # macOS / Linux  (или ./run.sh)
   alatyr.exe --config config.yaml        # Windows        (или run.bat)
   ```
3. Откройте `http://<IP-этой-машины>:8080/`, задайте пароль администратора,
   внешний адрес и порты протоколов.
4. «Новый пользователь» → имя → протокол → «Создать». Откроется окно с QR-кодом,
   ссылкой `vpn://` и кнопкой «Скачать .conf».
5. Разрешите в файрволе выбранные UDP-порты (и TCP `8080`, если заходите в
   веб-морду с другой машины).

## Клиенты

| Протокол      | Приложение                                                               |
|---------------|--------------------------------------------------------------------------|
| AmneziaWG 1.0 | любые AmneziaWG / AmneziaVPN                                             |
| AmneziaWG 2.0 | AmneziaWG / AmneziaVPN с поддержкой 2.0                                  |
| AmneziaWG 3.1 | свежие AmneziaWG / AmneziaVPN (3.x)                                      |
| WireGuard     | штатное приложение WireGuard, роутеры (Keenetic, MikroTik, OpenWrt)      |

`.conf` и QR «конфиг» — добавить в приложение «из файла / QR». `vpn://` — в
AmneziaVPN: «Добавить» → «Вставить ключ» (для WireGuard ссылки нет).

WireGuard по умолчанию выключен: он без обфускации и легко блокируется DPI.
Включается галочкой в «Настройках подключения».

## Порты и проброс через роутер

```
клиент ──UDP──► <внешний IP роутера>:<внешний порт> ──проброс──► <LAN-IP этой машины>:<внутренний порт> ──► alatyr
```

- **Внутренний порт** — UDP-порт, который слушает Alatyr.
- **Внешний порт** — порт на роутере, он попадает в `Endpoint` конфигов. Пусто = как внутренний.
- **Внешний адрес** — белый IP или домен (DDNS) роутера. Кнопка «Определить мой
  внешний IP» подставит его сама. Пока поле пустое, в конфиги идёт адрес
  страницы — из интернета такой конфиг не заработает.

Готовая таблица правил для роутера — в карточке «Проброс портов на роутере».

- Пробрасывайте только UDP; веб-морду (TCP 8080) в интернет не открывайте.
- Закрепите LAN-IP машины в роутере (DHCP-резервирование).
- Если IP в WAN-настройках роутера не совпадает с внешним или он из
  10.x / 100.64–127.x / 172.16–31.x / 192.168.x — у провайдера CGNAT, проброс
  не заработает, нужен белый IP.
- После смены внешнего адреса или порта юзерам протокола нужно заново выдать конфиги.

## Маршрутизация

Карточка «Маршрутизация» в веб-морде. Изменения применяются на лету, открытые
соединения не рвутся.

| Режим | Что происходит |
|---|---|
| Списки → через VPN, остальное напрямую (по умолчанию) | совпавшее с подписками и «Моими дополнениями» — в VPN, остальное — напрямую |
| Всё через VPN, кроме исключений | напрямую только «Мои исключения» и подписки с действием «напрямую» |
| Всё через VPN без разбора | правила не применяются; самый быстрый |

Приоритет: «Мои исключения» и «Мои дополнения» → подписки («через VPN» важнее
«напрямую») → режим по умолчанию.

**Подписки.** Включены заготовки: заблокированные в России сайты (itdoginfo),
подсети Telegram, gfwlist. По галочке — YouTube, antifilter (весь реестр —
~300 МБ памяти). Можно добавить любой URL: формат (списки доменов, подсети,
hosts, ABP/gfwlist и др.) определяется сам. Обновление — кнопкой или
автоматически раз в N часов.

Сайт определяется по DNS, SNI/Host и QUIC, так что правила работают, даже если
браузер использует свой DoH. Проверить, куда пойдёт адрес, — кнопка
«Проверить»; последние соединения — в журнале.

## config.yaml

```yaml
vpn: vpn.conf              # конфиг VPN-сервера (путь относительно config.yaml или абсолютный)
http_port: 8080            # порт веб-морды
# http_listen: 0.0.0.0     # 127.0.0.1 — веб-морда только локально
# public_host и ports — только начальные значения; дальше они меняются в веб-морде.
public_host: ""            # внешний адрес для конфигов. Пусто = адрес, по которому открыли веб-морду
# ports:                   # UDP-порты. Без секции — случайные свободные порты.
#   awg1: 51821            # С секцией: 0 или нет строки = протокол выключен
#   awg2: 51822
#   awg3: 51823
#   wg: 51820              # без строки WireGuard выключен, но порт подобран заранее
subnet: 10.66.66.0/24      # сеть юзеров; .1 — сам Alatyr
# dns: [1.1.1.1, 8.8.8.8]  # начальный DNS через туннель (по умолчанию из vpn.conf)
# mtu: 1280                # по умолчанию MTU из vpn.conf
data_file: alatyr-data.json
log_level: info            # info | debug
# log_file: alatyr.log     # писать лог ещё и в файл (для запуска без окна)
```

## Автозапуск

**Windows** — файлы рядом с `alatyr.exe`:

| Файл                    | Что делает                                         |
|-------------------------|----------------------------------------------------|
| `run.bat`               | запуск в окне консоли                              |
| `run-hidden.vbs`        | запуск без окна                                    |
| `stop.bat`              | остановить фоновый процесс                         |
| `autostart-windows.vbs` | включить/выключить автозапуск при входе в Windows  |

При запуске без окна включите `log_file` в `config.yaml`. Для старта до входа
пользователя — Планировщик заданий, триггер «При запуске».

**macOS / Linux:**

```sh
./service.sh install        # macOS: при входе пользователя
sudo ./service.sh install   # macOS: при загрузке; Linux: systemd-сервис
./service.sh status | logs | uninstall      # (с sudo, если ставили с sudo)
```

Если macOS ругается на неподписанный файл: `xattr -d com.apple.quarantine alatyr`.

## Безопасность

- Веб-морда работает по HTTP — не открывайте её в интернет. Удалённо — через
  `http_listen: 127.0.0.1` и `ssh -L 8080:127.0.0.1:8080 host`.
- `alatyr-data.json` содержит ключи юзеров — не выкладывайте его.
- Забыли пароль: остановите Alatyr, удалите строку `admin_password_hash` из
  `alatyr-data.json` — веб-морда попросит задать новый.

## Проверка подключения: awg-tester

Подключается по конфигу и проверяет рукопожатие, DNS, HTTP, внешний IP, пинг и скорость.

```sh
./awg-tester vasya.conf                 # конфиг юзера
./awg-tester "vpn://AAAC3Xja..."        # ключ AmneziaVPN
./awg-tester vpn.conf                   # сам VPN-сервер
```

Код выхода `0` — всё работает. Проверка маршрутизации: `-expect-tunnel <url>` /
`-expect-direct <url>` (запускать на машине с Alatyr).

## Ограничения

- Только IPv4: IPv6 в туннель не пускается, приложения сами переключаются на IPv4.
- Ping наружу всегда идёт через VPN.
