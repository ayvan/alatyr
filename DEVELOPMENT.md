# Alatyr — для разработки

## Сборка

Нужен Go (если локальный Go старее 1.25, он сам скачает нужный toolchain).

```sh
./build.sh          # ./alatyr и ./awg-tester под текущую машину
./build.sh all      # dist/alatyr-<os>-<arch>/ для Windows, macOS, Linux (amd64/arm64/arm)
                    # + dist/alatyr-windows-x64.zip и -arm64.zip
build.bat           # на Windows: alatyr.exe и awg-tester.exe
```

Сборка без CGO — один статический файл, веб-интерфейс вшит через `embed`.

Что кладётся в дистрибутивы: бинарники, `README.md`, `config.yaml`; для
macOS/Linux — `run.sh`, `service.sh`; для Windows — `run.bat`, `run-hidden.vbs`,
`stop.bat`, `autostart-windows.vbs` и всё из `packaging/windows/`, а в
`config.yaml` включается `log_file: alatyr.log`. Виндовые файлы хранятся в CRLF,
`INSTALL-RU.txt` — UTF-8 с BOM (чтобы Блокнот показал кириллицу).
`build.sh all` пересоздаёт только `dist/alatyr-*`.

## Тесты

```sh
go test ./...                                                        # юнит-тесты
ALATYR_VPN_CONF=$PWD/vpn.conf go test -tags e2e -v ./internal/e2e    # e2e через реальный VPN-сервер
  # TestRelay   — «всё через VPN» для каждого протокола: IP, 20 МБ, ping
  # TestRouting — дополнения/исключения, Host и SNI (в обход нашего DNS), подсеть
  #               Telegram, защита LAN, 20 МБ напрямую и через VPN,
  #               режим «всё, кроме исключений», переключение режимов на лету
```

## Устройство

- `internal/awgconf` — парсер/генератор конфигов AmneziaWG, UAPI, профили
  протоколов, `vpn://` (base64url(qCompress(conf)), как в AmneziaVPN).
- `internal/relay` — устройства amneziawg-go на in-memory TUN: клиент к
  апстриму и по одному слушателю на каждый протокол. TCP/UDP юзеров уходят в
  `internal/stack` (gVisor netstack), ICMP и режим «всё через VPN» — в пакетный
  NAT. Апстримный netstack и NAT делят адрес туннеля: netstack владеет портами
  10000–19999, NAT — остальными.
- `internal/router` — решение по каждому потоку (правила, сниффинг, DNS-кэш),
  дозвон напрямую или через апстрим, журнал и статистика.
- `internal/rules` — разбор списков и поиск; `internal/sniff` — SNI/Host/QUIC
  Initial; `internal/dns` — DNS для юзеров с кэшем «IP → имена»;
  `internal/lists` — подписки и их кэш; `internal/app` — сборка всего вместе.
- `internal/nat` — userspace SNAT на адрес из `vpn.conf`, с подменой
  портов/ICMP id и трансляцией ICMP-ошибок; таймауты UDP 3 мин, TCP 4 ч
  (1 мин после FIN/RST).
- `internal/store` — JSON-хранилище, `internal/web` — веб-морда.

### Маршрутизация

Имя сайта берётся из своего DNS на `10.66.66.1` (запросы на любой `:53`
перехватываются), SNI из TLS / `Host` из HTTP (порты 80, 443, 8080, 8443) и SNI
из QUIC Initial (UDP 443). Подсети решаются по первому пакету. Имена из правил
резолвятся через туннель, остальные — напрямую. AAAA и HTTPS-записи отдаются
пустыми (сеть IPv4-only, в HTTPS-записях приходят ключи ECH). При смене правил
открытые соединения доживают по старому маршруту.

### Протоколы

При первом запуске для каждого протокола генерируются ключи сервера и случайные
параметры обфускации (`servers.<протокол>` в `alatyr-data.json`), общие для всех
юзеров протокола. Сменить их — удалить `servers.<протокол>` и перезапустить,
после этого переиздать конфиги.

| Протокол      | Параметры                                                                                   |
|---------------|---------------------------------------------------------------------------------------------|
| AmneziaWG 1.0 | Jc, Jmin, Jmax, S1, S2, H1–H4 (одиночные значения)                                          |
| AmneziaWG 2.0 | + S3, S4, H1–H4 диапазонами, I1 (сигнатурный пакет «под STUN»)                               |
| AmneziaWG 3.1 | как в AmneziaVPN: HeaderProtectionKey, S1–S4 ≥ 12, RandomTrailers, DisableCookies, тайминги  |
| WireGuard     | без параметров: amneziawg-go без обфускации совместим с обычным WireGuard                   |

Апстрим (`vpn.conf`) может быть любой версии: поддерживаются все ключи
amneziawg-go 3.1. `Endpoint` может быть доменом — при пропаже рукопожатия он
переразрешается.

### Веб-морда

Пароль — bcrypt-хэш; сессия — HttpOnly-cookie SameSite=Strict на 7 дней
(сбрасывается при рестарте); CSRF-защита; 5 неверных паролей подряд —
блокировка IP на минуту. `alatyr-data.json` создаётся с правами `600`.

### Известные особенности

- В amneziawg-go 3.1 смещение под паддинг `S4` вычисляется до чтения первого
  пакета из TUN, поэтому первый пакет после старта устройства уходит без
  паддинга и отбрасывается. В ретрансляторе это обойдено (TUN «будится» после
  конфигурации); у клиентов на этой библиотеке первый пакет может теряться —
  обычно это лишь задержка первого запроса на несколько секунд.
- Прямой ICMP требует root, поэтому ping наружу всегда идёт через VPN.
